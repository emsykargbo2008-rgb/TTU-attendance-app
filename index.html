About This System

The TTU Smart Attendance System is a modern solution designed for Software Engineering Level 100 at Takoradi Technical University. Built with cutting-edge web technology, it provides administrators with an efficient way to manage attendance records for large student groups.

Created by Emmanuel Abubakarr Kargbo, this app combines clean mobile-first design and Firebase-powered reliability to make attendance tracking smooth for both admins and students.

300+ Students Handle large class sizes efficiently
Real-time Sync Firebase keeps data updated instantly
Role-based Access Admin and assistant admin roles
Offline Ready Works offline, syncs when online
